# National Student Wireless Research Club（NSWRC）公式サイト

GitHub Pages で公開する静的サイトです。日本語の正式名称は「全国学生無線通信研究会」、英語名称は **National Student Wireless Research Club**、略称は **NSWRC** です。

## ページ構成

- `index.html` — トップページ
- `news.html` — お知らせ一覧
- `news/<slug>.html` — お知らせ個別ページ
- `contact.html` — お問い合わせフォーム
- `news-admin.html` — ニュース原稿作成補助（管理者向け）
- `news-data.json` — 公開ニュースデータ
- `templates/news-article.html` — 個別ページの共通テンプレート
- `scripts/build-news.mjs` — ニュース個別ページ生成スクリプト

## お知らせの掲載・更新

1. `news-admin.html` で公開日、カテゴリ、記事URL用ID（slug）、タイトル、概要、本文を入力します。
2. 「入力内容を確認」で個別ページの表示イメージを確認し、JSONをダウンロードします。
3. 管理者が原稿を確認し、JSONオブジェクトを `news-data.json` の配列へ追加・更新します。slugは半角英小文字・数字・ハイフンで一意に設定してください。
4. リポジトリのルートで `node scripts/build-news.mjs` を実行します。各記事の個別HTMLが `news/` と `docs/news/` に生成されます。
5. `news-data.json` と生成されたHTMLを含めてGitHubへコミットします。

一覧ページは日付順に記事を表示し、各記事の個別URLへリンクします。個別ページはMarkdown本文を表示し、前後の記事と一覧へ戻る導線を備えています。対応記法は見出し、太字、斜体、取り消し線、インラインコード、コードブロック、箇条書き、番号付きリスト、引用、水平線、リンクです。トップページには最新3件のお知らせを表示します。ニュース作成画面ではMarkdownのリアルタイムプレビューと確認モーダルを利用できます。

ニュース作成画面は原稿作成を補助するもので、自動公開機能やログイン認証はありません。公開権限のある管理者のみがGitHub上でデータを更新してください。

## お問い合わせフォーム

現在のフォームは入力検証と送信前の案内まで実装していますが、送信先は未設定です。実際に問い合わせを受信するには、フォーム受付サービスまたはサーバー側APIを接続し、送信先・個人情報の取り扱い・スパム対策を設定する必要があります。送信先が接続されるまでは、フォームから問い合わせが届くことはありません。

## GitHub Pages

GitHub Pages の公開元を `main` ブランチの `/docs` に設定する場合は、`docs/` 内のHTML・CSS・JSONを更新してください。ニュース個別ページはビルドスクリプトが `docs/news/` にも生成します。ルート側も同じ内容に保つ運用です。

## 表示テスト記事について

現在 `news-data.json` にはMarkdown表示確認用の一時テスト記事が1件入っています。実運用を開始する際は、内容を正式なお知らせに差し替えるか、データ配列から削除して `node scripts/build-news.mjs` を再実行してください。
