# 全国学生無線通信研究会 公式サイト

GitHub Pages で公開する静的サイトです。サイト本体はルートと `docs/` に同じ内容を配置しています。

## ページ

- `index.html` — トップページ
- `news.html` — お知らせ一覧
- `contact.html` — お問い合わせフォーム
- `news-admin.html` — ニュース原稿作成補助（管理者向け）
- `news-data.json` — 公開ニュースデータ

## ニュースの更新

1. `news-admin.html` を開き、日付・カテゴリ・タイトル・概要を入力します。
2. プレビューを確認し、JSONをダウンロードします。
3. 管理者が内容を確認したうえで、JSONオブジェクトを `news-data.json` の配列に追加します。
4. ルートと `docs/` の両方の `news-data.json` を同期し、GitHubへコミットします。

ニュース作成画面は原稿作成を補助するもので、サイトへの自動公開機能やログイン認証はありません。公開権限のある管理者のみがGitHub上でデータを更新してください。

## お問い合わせフォーム

現在のフォームは入力検証と送信前の案内まで実装していますが、送信先は未設定です。実際に問い合わせを受信するには、Formspree等のフォーム受付サービス、またはサーバー側APIを用意し、送信先・個人情報の取り扱い・スパム対策を設定する必要があります。送信先が接続されるまでは、フォームから問い合わせが届くことはありません。

## GitHub Pages

GitHub Pages の公開元を `main` ブランチの `/docs` に設定する場合は、`docs/` 内のHTML・CSS・JSONを更新してください。ルート側も同じ内容に保つ運用です。
